"@universal-middleware/h3": minor
---

Supports h3 v2 only (`h3@^2`). Stay on `@universal-middleware/h3@^0.6` for h3 v1.

- Middlewares are h3 v2 middlewares (`(event, next)`): response functions run around `next()`, so `universalOnBeforeResponse` is gone. Remove `onBeforeResponse: universalOnBeforeResponse` from the app options.
- `createApp()` and `createRouter()` become `new H3()`. `App` is now an alias of h3's `H3`.
- The universal middlewares and handlers get h3's own `event.req`. `getRuntime(event)` reads `env`, `ctx` and the Node `req`/`res` from `event.runtime`, and `ctx.waitUntil` is set when the runtime provides one.
